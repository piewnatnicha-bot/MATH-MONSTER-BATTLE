# Math Monster RPG 3D — GitHub Pages

เกม RPG 3D โลกเปิดขนาดเล็ก เล่นผ่านมือถือและคอมพิวเตอร์: ตัวละครวิ่ง/แกว่งแขนขา, มอนสเตอร์เคลื่อนไหวและไล่ผู้เล่น, NPC ลูน่าให้เควส, เนื้อเรื่อง 3 บท, การต่อสู้ด้วยโจทย์คณิต, บอส, XP, เหรียญ, อุปกรณ์คทา/เกราะ/รองเท้า, บันทึกอัตโนมัติด้วย localStorage

## ติดตั้ง
1. แตก ZIP แล้วอัปโหลด **ไฟล์ภายในโฟลเดอร์** ทั้งหมด (`index.html`, `app.js`, `icon.svg`, `manifest.webmanifest`, `README.md`) ไปที่ root ของ GitHub repository แบบ Public
2. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save
3. เปิด `https://USERNAME.github.io/REPOSITORY/` หลัง GitHub Pages deploy เสร็จ
4. บนมือถือ เปิดใน Safari/Chrome; ใช้จอยซ้ายมือและปุ่มโจมตี/คุยขวามือ

## วิธีเล่น
- คุยกับลูน่าใกล้จุดเริ่มต้นเพื่อรับเควส
- กำจัดมอนสเตอร์ด้วยการตอบโจทย์คณิตให้ถูก (14 วินาทีต่อคำถาม)
- เมื่อเควสครบ กลับไปส่งกับลูน่า; ด่านสุดท้ายมีบอส
- กดกระเป๋าเพื่ออัปเกรดอุปกรณ์ด้วยเหรียญ
- คอมพิวเตอร์: WASD/ลูกศร เดิน, Space โจมตี, E คุย, I อุปกรณ์

## หมายเหตุ
- ใช้ Three.js 0.149.0 จาก jsDelivr CDN จึงต้องมีอินเทอร์เน็ตเพื่อโหลดไลบรารี; ไม่มีเซิร์ฟเวอร์และไม่ต้องล็อกอิน
- ความคืบหน้าเก็บใน localStorage ของเบราว์เซอร์ที่เล่น; ไม่ซิงก์ข้ามเครื่อง
- แอนิเมชันทำด้วยการขยับโมเดล 3D แบบ procedural ไม่ใช่ motion capture / rigged character animation
- รองรับ WebGL บนอุปกรณ์สมัยใหม่ แต่ประสิทธิภาพขึ้นกับโทรศัพท์
