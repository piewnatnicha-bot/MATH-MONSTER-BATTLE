# Math Monster RPG 3D — 7 ด่าน จำนวนเต็ม + เสียงประกอบ

## การติดตั้งบน GitHub Pages
อัปโหลดไฟล์ **ทั้งหมด** ในโฟลเดอร์นี้ (`index.html`, `app.js`, `icon.svg`, `manifest.webmanifest`) ไปที่ root ของ Repository `MATH-MONSTER-BATTLE` แล้ว Commit; ใน Settings → Pages ใช้ main / (root).

## เนื้อหา 7 ด่าน
1. ป่าสายรุ้ง — บวกจำนวนเต็ม (รวมจำนวนลบและศูนย์)
2. หมู่บ้านดอกไม้ — ลบจำนวนเต็ม
3. สวนผลไม้มหัศจรรย์ — บวกและลบจำนวนเต็มผสม
4. ป่าเห็ดแสนสนุก — คูณจำนวนเต็ม
5. หมู่บ้านริมลำธาร — หารจำนวนเต็ม (ตัวหารไม่เป็นศูนย์)
6. ป่าคริสตัลสีรุ้ง — บวก ลบ คูณ หาร ผสม
7. หมู่บ้านปราสาทสายรุ้ง — ทบทวน 4 การดำเนินการและปราบบอส

## เสียง
มีเสียงกด/รับเควส โจมตี ตอบผิด บาดเจ็บ ชนะ และทำนองประกอบเบา ๆ สร้างจาก Web Audio API โดยไม่ต้องโหลดไฟล์เสียงภายนอก; iPhone ต้องกด 'เริ่มผจญภัย' เพื่อเปิดเสียง; ปิดเปิดได้ด้วยปุ่ม 🔊 เสียง.

## หมายเหตุ
- ใช้ Three.js จาก CDN ต้องมีอินเทอร์เน็ตในการเปิดเกม
- ใช้ localStorage ชื่อ `math-monster-rpg-7stage-v1` แยกจากเซฟเก่า 3 ด่าน เพื่อไม่ให้สถานะเควสเก่าทำให้เกมข้ามด่าน; เซฟเก่าไม่ถูกลบ
- เกมยังไม่ผ่านการทดสอบ WebGL บน iPhone จริง; ตรวจ syntax JS แล้ว
- ไฟล์ใน ZIP ต้องอัปโหลดแยก ไม่ใช่อัปโหลด ZIP ทั้งไฟล์
