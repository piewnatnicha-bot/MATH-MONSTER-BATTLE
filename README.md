# Math Monster RPG 3D — Free World & Challenge League

เกม 3D คณิตศาสตร์จำนวนเต็ม 7 ด่าน พร้อมโลกอิสระหลังจบเกม ระบบเสียง เขาวงกต เควสดอกไม้ ร้านแฟชั่น บ้านส่วนตัว และลีกแข่งขัน 3 ด่านที่เล่นซ้ำได้

## วิธีติดตั้ง GitHub Pages

1. แตก ZIP แล้วอัปโหลดไฟล์ `index.html`, `app.js`, `icon.svg`, `manifest.webmanifest`, `README.md` ไปยัง root ของ repository `MATH-MONSTER-BATTLE` (แทนที่ไฟล์เดิม)
2. กด Commit changes แล้วรอ GitHub Pages deploy
3. เปิด `https://piewnatnicha-bot.github.io/MATH-MONSTER-BATTLE/`
4. โหลด Three.js จาก CDN จึงต้องมีอินเทอร์เน็ตเมื่อเปิดเกม

## วิธีเล่น

- WASD / ปุ่มลูกศร หรือจอยสติ๊กบนจอ = เดิน
- Space / ปุ่มโจมตี = โต้ตอบตามบริบท: ลูน่า, ดอกไม้, ศูนย์บัญชาการ, โจมตีมอนสเตอร์, วางบ้าน
- E = คุยกับลูน่า, I / ปุ่มกระเป๋า = ร้านค้าในโลกอิสระ
- เมื่อจบ 7 ด่าน จะเข้าสู่โลกอิสระ: เดินไปใกล้ดอกไม้ยักษ์แล้วกด Space หรือแตะดอกไม้ใกล้ตัวเพื่อรับโจทย์สะสมเหรียญและ XP
- ไปที่อาคารหลังคาสีฟ้าบริเวณกลางหมู่บ้าน แล้วกด Space เพื่อสมัครแข่งขัน 3 ด่าน: บวก/ลบ, คูณ/หาร, ผสมทั้งสี่การดำเนินการและบอส
- ชนะครบ 3 ด่านจะได้รับโบนัสและฉากฉลอง ก่อนกลับสู่โลกอิสระ สมัครแข่งใหม่ได้ไม่จำกัดครั้ง
- เปิดกระเป๋าในโลกอิสระเพื่อซื้อเสื้อ กระโปรง หมวก และบ้าน ซื้อเสื้อผ้าแล้วกดสวมใส่/ถอดได้ทันที
- ซื้อบ้านแล้วกด 'เลือกตำแหน่งวางบ้าน' เดินไปยังพื้นที่โล่ง และกด Space หรือปุ่มวางบ้าน (E ยกเลิก) บ้านที่วางไว้คงอยู่หลังรีโหลด
- บ้านต้องวางในพื้นที่เดินได้ โดยไม่ทับกำแพงเขาวงกต บ้านอื่น ดอกไม้ ศูนย์บัญชาการ หรือลูน่า

## ข้อมูลบันทึก

ใช้ localStorage key เดิม `math-monster-rpg-7stage-v1` เพื่อเก็บเหรียญ, XP, ด่าน, อุปกรณ์, เสื้อผ้า, บ้าน, จำนวนรอบแข่งขัน และเควสดอกไม้ บันทึกแยกตามเบราว์เซอร์/อุปกรณ์ ไม่ใช่ระบบบัญชีออนไลน์

**หมายเหตุ:** ระบบบ้านใช้โมเดลบ้านพาสเทลหนึ่งแบบที่สลับสีหลังคาตามจำนวนบ้าน และระบบแต่งตัวเป็นชิ้นส่วน 3D ที่สร้างจากรูปทรงเรขาคณิต (ไม่ใช่โมเดลตัวละครแบบมีเสื้อผ้าผ้าจริง) โจทย์ไม่มีการหารด้วยศูนย์
